## ⏰ 일일 30분 데일리 학습 루틴 (3-Step Daily Routine)

왕초보가 8일 만에 회화를 터뜨리는 핵심은 **"문법 공부 금지, 1초 패턴 반사신경 훈련"**입니다.

```
[아침 기상 / 출근길 10분]  ➔  1초 패턴 5개 소리 내어 말하기 (오디오 TTS 청취)
[점심 식사 후 10분]        ➔  웹 테스트 앱에서 상황별 퀴즈 10문제 풀기
[퇴근 / 취침 전 10분]      ➔  당일 미션 롤플레잉(시뮬레이션) + 단어장 복습
```

## 🎯 학습 성과 점검 기준 (Checklist)

- [ ] **반사적 반응**: 눈앞의 직원이 물어볼 때 당황하지 않고 `코레 쿠다사이`나 `다이죠-부데스`가 0.5초 만에 나오는가?

- [ ] **요청 패턴**: `~와 도코데스카?`(어디인가요), `~오네가이시마스`(부탁합니다)를 자유자재로 붙일 수 있는가?
