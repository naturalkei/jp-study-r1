# 📖 도쿄·관광지 실전 필수 단어 및 문장 암기장

> **Tip**: 각 문장 옆의 한글 발음은 일본인이 가장 자연스럽게 알아듣는 억양과 장음(`-`)을 반영하여 표기했습니다.

## 🛫 1. 공항 & 이동 (나리타 ➔ 도쿄 ➔ 관광지)

### 📌 필수 단어장
| 한국어 | 일본어 (한자/가나) | 발음 (한글 독음) | 비고 |
|:---|:---|:---|:---|
| 나리타 공항 | 成田空港 (なりたくうこう) | 나리타 쿠-코- | Narita Airport |
| 관광지역 | 河口湖駅 (かわぐちこえき) | 관광지 에키 | Kawaguchiko Station |
| 우에노역 | 上野駅 (うえのえき) | 우에노 에키 | Ueno Station |
| 매표소 / 창구 | 切符売り場 (きっぷうりば) | 킵푸 우리바 | Ticket office |
| 승강장 / 플랫폼 | 乗り場 (のりば) | 노리바 | Bus/Train platform |
| 스카이라이너 | スカイライナー | 스카이라이나- | Keisei Skyliner (우에노-나리타) |
| 고속버스 | 高速バス (こうそくバス) | 코-소쿠 바스 | Express bus |
| 교통카드 (스이카) | Suica (スイカ) | 스이카 | IC Card |
| 충전 | チャージ | 챠-지 | Charge |

| 환전소 | 両替所 (りょうがえじょ) | 료-가에죠 | Currency exchange |

### 💬 필수 회화 문장
1. **나리타 공항에서 관광지행 버스표 끊기**
   - **JP**: 河口湖行きのバスのチケットを2枚ください。
   - **발음**: 관광지 유키노 바스노 치켓토오 니마이 쿠다사이.
   - **해석**: 관광지행 버스 티켓 2장 주세요.

2. **승강장 위치 묻기**
   - **JP**: 河口湖行きの乗り場は何番ですか？
   - **발음**: 관광지 유키노 노리바와 난반데스카?
   - **해석**: 관광지행 타는 곳은 몇 번인가요?

3. **교통카드 충전 요청**
   - **JP**: Suicaをチャージしたいです。
   - **발음**: 스이카 카-도오 챠-지 시타이데스.
   - **해석**: 스이카(교통카드) 충전하고 싶습니다.

4. **스카이라이너 시간 확인 (우에노 ➔ 나리타 귀국 시)**
   - **JP**: 成田空港行きのスカイライナーは何時ですか？
   - **발음**: 나리타 쿠-코- 유키노 스카이라이나-와 난지데스카?
   - **해석**: 나리타 공항행 스카이라이너는 몇 시인가요?

## 🏨 2. 호텔 (관광지 파크 & 칸데오 호텔 우에노코엔)

### 📌 필수 단어장
| 한국어 | 일본어 (한자/가나) | 발음 (한글 독음) | 비고 |
|:---|:---|:---|:---|
| 예약 | 予約 (よやく) | 요야쿠 | Reservation |
| 체크인 / 체크아웃 | チェックイン / チェックアウト | 체크인 / 체크아우토 | Check-in / Out |
| 짐 / 여행가방 | 荷物 (にもつ) / スーツケース | 니모츠 / 수-츠케-스 | Baggage |
| 여권 | パスポート | 파스포-토 | Passport |
| 대욕장 / 스파 / 온천 | 大浴場 (だいよくじょう) / スパ / 温泉 | 다이요쿠죠- / 스파 / 온센 | 칸데오 스카이스파 / 관광지 |
| 수건 | タオル | 타오루 | Towel |
| 룸 키 / 카드키 | 部屋の鍵 (へやのかぎ) / ルームキー | 헤야노 카기 / 루-무 키- | Room key |
| 금연실 / 흡연실 | 禁煙室 (きんえんしつ) / 喫煙室 | 킨엔시츠 / 키츠엔시츠 | Non-smoking |
| 조식 (아침식사) | 朝食 (ちょうしょく) | 쵸-쇼쿠 | Breakfast |
| 와이파이 비밀번호 | Wi-Fiのパスワード | 와이파이노 파스와-도 | Wi-Fi password |

### 💬 필수 회화 문장
1. **호텔 체크인 시작**
   - **JP**: チェックインをお願いします。予約した[이름]です。
   - **발음**: 체크인오 오네가이시마스. 요야쿠시타 [이름] 데스.
   - **해석**: 체크인 부탁드립니다. 예약자 [이름]입니다.

2. **체크인 전 / 체크아웃 후 짐 보관 요청 (가장 중요!)**
   - **JP**: チェックイン前に、荷物を預けることはできますか？
   - **발음**: 체크인 마에니, 니모츠오 아즈케루 코토와 데키마스카?
   - **간단 발음**: 니모츠오 아즈캇테 이타다케마스카? (짐 좀 맡아주실 수 있나요?)
   - **초간단**: 니모츠, 오네가이시마스! (짐 부탁합니다!)

3. **짐 찾을 때 (보관증 건네며)**
   - **JP**: 荷物をお願いします。
   - **발음**: 니모츠오 오네가이시마스.
   - **해석**: (보관증 주며) 짐 부탁드립니다.

4. **칸데오 호텔 우에노 스카이스파 / 대욕장 이용 안내 문의**
   - **JP**: スパ（大浴場）は何時から何時までですか？
   - **발음**: 스파(다이요쿠죠-)와 난지카라 난지마데데스카?
   - **해석**: 스파(대욕장)는 몇 시부터 몇 시까지인가요?

5. **어메니티/수건 추가 요청**
   - **JP**: バスタオルをもう1枚いただけますか？
   - **발음**: 바스타오루오 모- 이치마이 이타다케마스카?
   - **간단 발음**: 타오루 모- 히토츠 오네가이시마스. (수건 하나 더 부탁합니다)

## 🍜 3. 식당 & 맛집 (관광지 호우토우 & 우에노 이자카야/라멘)

### 📌 필수 단어장
| 한국어 | 일본어 (한자/가나) | 발음 (한글 독음) | 비고 |
|:---|:---|:---|:---|
| 인원수 (1명/2명) | 1人 (ひとり) / 2人 (ふたり) | 히토리 / 후타리 | Party size |
| 물 (찬물) | お水 (おみず) / お冷 (おひや) | 오미즈 / 오히야 | Water |
| 생맥주 | 生ビール (なまビール) | 나마비-루 | Draft beer |
| 추천 | おすすめ | 오스스메 | Recommendation |
| 호우토우 | ほうとう | 호-토- | 관광지 명물 칼국수 나베 |
| 라멘 | ラーメン | 라-멘 | Ramen |
| 닭꼬치 | 焼き鳥 (やきとり) | 야키토리 | Yakitori |
| 계산서 | お会計 (おかいけい) | 오카이케이 | Bill / Check |
| 영수증 | レシート / 領収書 (りょうしゅうしょ) | 레시-토 / 료-슈-쇼 | Receipt |
| 포장 (테이크아웃) | 持ち帰り (もちかえり) / テイクアウト | 모치카에리 / 테이쿠아우토 | Takeout |

### 💬 필수 회화 문장
1. **식당 입장 시 인원 말하기**
   - **JP**: 2人です。
   - **발음**: 후타리데스.
   - **해석**: 2명입니다.

2. **메뉴 추천 묻기**
   - **JP**: おすすめは何ですか？
   - **발음**: 오스스메와 난데스카?
   - **해석**: 추천 메뉴가 무엇인가요?

3. **이자카야 착석 직후 주문 1순위**
   - **JP**: とりあえず生ビール2つお願いします！
   - **발음**: 토리아에즈 나마비-루 후타츠 오네가이시마스!
   - **해석**: 우선 생맥주 2잔 부탁드립니다!

4. **사진이나 메뉴판 가리키며 주문하기**
   - **JP**: これとこれを1つずつください。
   - **발음**: 코레토 코레오 히토츠즈츠 쿠다사이.
   - **해석**: 이거랑 이거 하나씩 주세요.

5. **물 부탁하기**
   - **JP**: お冷をお願いします。
   - **발음**: 오히야오 오네가이시마스. (또는 '오미즈 오네가이시마스')
   - **해석**: 물 좀 주세요.

6. **계산하기 (자리 또는 카운터에서)**
   - **JP**: お会計をお願いします。カードは使えますか？
   - **발음**: 오카이케이오 오네가이시마스. 카-도와 츠카에마스카?
   - **해석**: 계산 부탁드립니다. 카드 쓸 수 있나요?

## 🛍️ 4. 쇼핑 & 편의점 (우에노 아메요코, 돈키호테, 로손)

### 📌 필수 단어장
| 한국어 | 일본어 (한자/가나) | 발음 (한글 독음) | 비고 |
|:---|:---|:---|:---|
| 면세 | 免税 (めんぜい) | 멘제- | Tax free |
| 비닐봉투 | レジ袋 (レジぶくろ) / 袋 (ふくろ) | 레지부쿠로 / 후쿠로 | Plastic bag |
| 젓가락 / 숟가락 | 箸 (おはし) / スプーン | 오하시 / 스푸-ㄴ | Chopsticks / Spoon |
| 데우기 (전자레인지) | 温め (あたため) | 아타타메 | Heating up |
| 신용카드 / 현금 | クレジットカード / 現金 (げんきん) | 쿠레짓토 카-도 / 겐킨 | Card / Cash |
| 선물용 포장 | プレゼント用 (プレゼントよう) | 푸레젠토요- | Gift wrap |
| 다른 색상 / 사이즈 | 違う色 (ちがういろ) / サイズ | 치가우 이로 / 사이즈 | Color / Size |

### 💬 필수 회화 문장
1. **편의점에서 봉투 요청**
   - **JP**: 袋を1枚お願いします。
   - **발음**: 후쿠로오 이치마이 오네가이시마스.
   - **해석**: 봉투 한 장 주세요. (불필요시: "다이죠-부데스")

2. **도시락 데워달라고 하기**
   - **JP**: これ、温めてもらえますか？
   - **발음**: 코레, 아타타메테 모라에마스카?
   - **해석**: 이거 데워주실 수 있나요?

3. **돈키호테 / 쇼핑몰 면세 문의**
   - **JP**: 免税はできますか？免税カウンターはどこですか？
   - **발음**: 멘제-와 데키마스카? 멘제- 카운타-와 도코데스카?
   - **해석**: 면세 되나요? 면세 카운터는 어디인가요?

4. **재고 확인 (스마트폰 사진 보여주며)**
   - **JP**: これ、在庫ありますか？
   - **발음**: 코레, 자이코 아리마스카?
   - **해석**: 이거 재고 있나요?

## 🚨 5. 긴급 & 돌발 대처

1. **화장실 찾기**:
   - `토이레와 도코데스카?` (화장실은 어디인가요?)
2. **길을 잃었을 때 (지도/화면 가리키며)**:
   - `코코니 이키타이데스. 도- 얏테 이키마스카?` (여기에 가고 싶습니다. 어떻게 가나요?)
3. **분실물이 생겼을 때**:
   - `[모노]오 와스레마시타.` ([물건]을 두고 왔습니다.)
   - 예: `스마-토폰오 와스레마시타.` (스마트폰을 두고 왔습니다.)
4. **몸이 아플 때 / 약국에서**:
   - `즈츠-야쿠(두통약) 아리마스카?`
   - `소-카츠야쿠(소화제) 아리마스카?`
