# 🚀 1초 완성 일본어 회화 만능 치트시트 (도쿄·후지산 여행용)

> **💡 왕초보 생존 원칙**
> 1. 긴 문장을 만들려 하지 마세요. **[단어 + 쿠다사이 / 오네가이시마스]** 면 95% 통합니다.
> 2. 모르거나 거절할 때는 손을 살짝 저으며 **[다이죠-부데스]**!
> 3. 직원이 다가오거나 사람을 부를 때는 무조건 **[스미마센]**!

---

## ⭐️ [핵심 1] 왕초보를 구원하는 3대 마법 단어

| 한국어 발음 | 일본어 표기 | 의미 / 쓰이는 순간 |
|:---|:---|:---|
| **스미마센** | すみません | 저기요 / 실례합니다 / 죄송합니다 / (물건 받을 때) 감사합니다 |
| **코레 쿠다사이** | これ ください | (손가락으로 가리키며) 이거 주세요! |
| **다이죠-부데스** | 大丈夫です | 괜찮습니다 (No thank you / 거절 / I'm okay) |

---

## 🔑 [핵심 2] 5대 만능 조립 공식

단어 하나만 끼워 넣으면 질문과 요청이 모두 완성됩니다.

### 1. `~와 도코데스카?` ( ~은/는 어디인가요? )
- **토이레**와 도코데스카? (화장실은 어디인가요?)
- **가와구치코 바스노리바**와 도코데스카? (가와구치코 버스 승강장은 어디인가요?)
- **스카이라이나-**와 도코데스카? (스카이라이너 타는 곳은 어디인가요?)

### 2. `~ 오네가이시마스` ( ~ 부탁합니다 / 주세요 )
- **체크인** 오네가이시마스 (체크인 부탁합니다)
- **니모츠** 오네가이시마스 (짐 좀 맡아주세요)
- **오카이케이** 오네가이시마스 (계산 부탁합니다)
- **미즈** 오네가이시마스 (물 좀 주세요)

### 3. `~ 데키마스카?` ( ~ 되나요? / 할 수 있나요? )
- **카-도** 데키마스카? (카드 결제 되나요?)
- **멘제-** 데키마스카? (면세 되나요?)
- **와이파이** 데키마스카? (와이파이 되나요?)

### 4. `~ 아리마스카?` ( ~ 있나요? )
- **에-고노 메뉴-** 아리마스카? (영어 메뉴판 있나요?)
- **캉코쿠고 메뉴-** 아리마스카? (한국어 메뉴판 있나요?)
- **코레, 아리마스카?** (사진 보여주며: 이거 재고 있나요?)

### 5. `이쿠라데스카?` ( 얼마인가요? )
- **젠부데 이쿠라데스카?** (전부 합쳐서 얼마인가요?)

## 💴 [핵심 3] 숫자 & 돈 계산 10초 마스터

점원이 계산대 화면(모니터)을 보여주거나 금액을 말할 때 바로 알아듣는 팁!

| 숫자 | 일본어 발음 | 실전 금액 예시 | 일본어 발음 |
|:---:|:---|:---|:---|
| 1 | 이치 (1) | **100엔 (약 900원)** | 햐쿠엔 |
| 2 | 니 (2) | **500엔 (약 4,500원)** | 고햐쿠엔 |
| 3 | 산 (3) | **1,000엔 (약 9,000원)** | 센엔 |
| 4 | 욘 / 시 (4) | **2,000엔** | 니센엔 |
| 5 | 고 (5) | **5,000엔** | 고센엔 |
| 6 | 로쿠 (6) | **10,000엔 (약 9만원)** | 이치만엔 |
| 7 | 나나 / 시치 (7) | **1,500엔** | 센고햐쿠엔 |
| 8 | 하치 (8) | **3,800엔** | 산젠핫퍄쿠엔 |
| 9 | 큐- (9) | **소비세 포함 (중요)** | 제-코미 (税込) |
| 10 | 쥬- (10) | **소비세 별도** | 제-누키 (税抜) |

> 💡 **Tip**: 귀로 못 알아들었을 때는 손짓으로 계산기나 화면을 가리키며:
> **"미세테 쿠다사이"** (보여주세요) 또는 스마트폰 계산기를 건네주세요.

## 📍 [장소별] 상황 즉각 대처 한 줄 회화

### 1. 인천공항 & 나리타 공항
- **코레, 가와구치코 유키데스카?** (이거 가와구치코 가는 편인가요?)
- **스이카 카-도 챠-지 데키마스카?** (스이카 카드 충전 되나요?)
- **스카이라이나-노 치켓토 오네가이시마스** (스카이라이너 티켓 부탁합니다)

### 2. 가와구치코 파크 호텔 & 칸데오 호텔 우에노
- **요야쿠시타 [성함] 데스** (예약한 [성함]입니다)
- **체크인데스. 코레, 파스포-토데스** (체크인입니다. 여기 여권입니다)
- **체크인마에니 니모츠오 아즈케테모 이이데스카?** (체크인 전에 짐을 맡겨도 될까요?)
  - *초간단 버전*: **"니모츠, 다이죠-부데스카?"**
- **스카이스파(온센)와 난지마데데스카?** (스카이스파/온천은 몇 시까지인가요?)
- **타오루 히토츠 오네가이시마스** (수건 하나 부탁합니다)

### 3. 편의점 (로손 / 세븐일레븐 / 패밀리마트) - 직원 질문 3대장 대응
1. 직원이 봉투를 물어볼 때 (`袋はお付けしますか？` / `후쿠로와 오츠케시마스카?` / 봉투 필요하신가요?):
   - 필요 없을 때: **다이죠-부데스** (괜찮습니다 / 大丈夫です)
   - 필요할 때: **후쿠로 오네가이시마스** (봉투 부탁합니다 / 袋お願いします)
2. 도시락/삼각김밥 데워드릴까요? (`温めますか？` / `아타타메마스카?`):
   - 데워주세요: **하이, 오네가이시마스** (네, 부탁합니다 / はい、お願いします)
   - 괜찮아요: **다이죠-부데스** (괜찮습니다 / 大丈夫です)
3. 젓가락/숟가락 (`お箸はお付けしますか？` / `오하시와 오츠케시마스카?`):
   - **오하시 오네가이시마스** (젓가락 부탁해요 / お箸お願いします)
   - **스푸-ㄴ 오네가이시마스** (숟가락 부탁해요 / スプーンお願いします)

### 4. 식당 & 맛집 (호우토우 / 라멘 / 이자카야)
- **후타리데스** (2명입니다) / **히토리데스** (1명입니다)
- **오스스메와 난데스카?** (추천 메뉴가 무엇인가요?)
- **토리아에즈 나마 후타츠 오네가이시마스** (우선 생맥주 2잔 부탁합니다)
- **코레토 코레 쿠다사이** (이거랑 이거 주세요)
- **오카이케이 오네가이시마스** (계산서 주세요)
- **베츠베츠데 데키마스카?** (더치페이/따로 계산 되나요?)

### 5. 쇼핑 (우에노 아메요코, 돈키호테)
- **멘제- 카운타-와 도코데스카?** (면세 카운터는 어디인가요?)
- **아타라시이 모노 아리마스카?** (새 상품 있나요?)
- **코레, 사가시테이마스** (사진 보여주며: 이거 찾고 있어요)

### 6. 위급 & 긴급 상황
- **토이레와 도코데스카?** (화장실이 어디인가요?)
- **타스케테 쿠다사이** (도와주세요)
- **니모츠오 와스레마시타** (짐을 두고 내렸습니다/잃어버렸습니다)
- **캉코쿠고 데키루 히토 이마스카?** (한국어 할 수 있는 사람 있나요?)
